JNV
JNV stands for Jawahar Navodaya Vidyalaya, a highly successful system of central government residential schools in India designed to find and nurture talented children, predominantly from rural areas. Ordered List
An ordered list is a sequential group of related items marked with numbers, letters, or Roman numerals to indicate importance or order.In digital formatting, it is primarily used in HTML programming via the
    tag, but it is also supported in plain text and Markdown using standard digits followed by a period
Unordered List
An unordered list is a collection of related items whose order does not matter. In digital formatting and web development, it is typically rendered using bullet points
Description List
An HTML description list is a specialized list format used to display groups of terms alongside their corresponding descriptions, values, or definitions. Formerly known as a "definition list," it functions like a dictionary or glossary on a webpage
